目标：
  Analysis Group 仅输出三个目标级次的效率与相位：
  eta_m1、eta_0、eta_p1、phi_m1、phi_0、phi_p1。

前提：
  1. 监视器名称为 T，且位于该 Analysis Group 内。
  2. 透射进入 SiO2 基底，故 output_index=1.45、projection_direction=-1。
  3. T 的位置、偏振、工作波长和投影方向在全部扫描中保持不变。

配置：
  1. 右键 analysis group，选择 Edit object。
  2. 打开 Analysis -> Variables。
  3. 在 Results 区域仅添加以下六个结果名：

       eta_m1
       eta_0
       eta_p1
       phi_m1
       phi_0
       phi_p1

  4. 打开 Analysis -> Script，粘贴 analysis_group_T_orders_script.lsf。
  5. 点击 OK；单次 FDTD 仿真结束后运行 Run Analysis，确认六个结果均有数值。

结果含义：
  eta_m1、eta_0、eta_p1：
    N=-1、0、+1 级相对于入射功率的透射效率。

  phi_m1、phi_0、phi_p1：
    对应级次复 Ex 投影的相位，单位 rad，范围 [0,2*pi)。

Parameter Sweep：
  在 Sweep 的 Results 区域仅添加以下完整路径：

       ::model::analysis group::eta_m1
       ::model::analysis group::eta_0
       ::model::analysis group::eta_p1
       ::model::analysis group::phi_m1
       ::model::analysis group::phi_0
       ::model::analysis group::phi_p1

  不要将监视器 T 的 E/H 场、order_results 或其他矩阵加入 Sweep Results。
